PASS: no $fatal, full self-checking suite completes, final PASS ALL.
Testcases: normal [19 22; 43 50], zero, identity, maximum
130050, change input while busy, ignore start while busy,
asynchronous reset, exactly eight calculation cycles, done pulse,
and 120 pseudo-random testcases.

DVE: navigate to tb_matrix_mul_2x2 hierarchy. Select
clk, rst_n, start, A_flat, B_flat, C00, C01, C10, C11, busy,
done; right-click Add to Waves -> New Wave View; Start/Continue.
Save waveform screenshots for edge 0, edges 1-8 and done pulse,
maximum input case, reset while busy. The TB also dumps
matrix_mul_2x2_rtl.vcd for offline wave inspection.
Note: the TB waveform is not an SDF timing waveform.

E. MODULE 3 SEC 2.4: POWER (VPD -> VCD -> SAIF)
------------------------------------------------
# In gate_run with the VCS environment still active:
vcs -full64 -sverilog -debug_access+all +neg_tchk \
  +define+GATE_SDF+VCS_VPD -top tb_matrix_mul_2x2_gate \

  -f ./library.f -o simv_gate -l power_compile.log
