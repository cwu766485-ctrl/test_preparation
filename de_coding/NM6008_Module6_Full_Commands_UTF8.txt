D. 报错速查
======================================================================
innovus: Command not found         → 切 csh / source cshrc_inno / which innovus
setExtractRCMode: Command not found→ 检查是否在 Linux shell，应该进入 innovus N>
report_saif: Command not found     → 属于 Synopsys 工具域，不是普通 shell/Innovus 指令
restoreDesign: Command not found   → 对本机的保存脚本用 source save_design/CHECKPOINT
GLIBC_2.25/2.27/2.28 not found  → Quantus 新版与 CentOS 7 旧 libc 不兼容，按更新免做 Section 13
LS_PLACEOPT::runCurrentState      → 联动 Quantus/RC 失败、路径/环境/数据库状态，先检查日志与依赖
NREX-94 11 routing layers / 1 mapped → 检查 QRC 物理层映射与对应 tech，不要把二进制 qrcTechFile 当文本改
Hold WNS 为负                  → Post-CTS check → optDesign -postCTS -hold → Post-Route 重新检查
19 / 1 DRC Violation           → verify_drc 定位 Short/Spacing → 保存检查点 → 针对性 ECO → 再检查
verifyConnectivity 输出 Killed  → 可能遭 OS OOM killer，检查内存/日志、避免无约束重复运行
GDS 为空或尺寸不对            → 检查 streamOut mapFile、libName、structureName、错误摘要
SDF 不存在                    → 在 Innovus 检查 write_sdf 的输出与时序视图
