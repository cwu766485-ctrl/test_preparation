# 04 · Memory and interfaces

This section includes asynchronous dual-port RAM, synchronous/asynchronous
FIFOs, and parallel/serial converters. Read each child README for port timing,
reset behavior, and the exact testbench scenarios.

In a module folder run `make test`, inspect the read/write or ready/valid
waveform, then run `make clean`. Synthesis/report guidance is in
[`../tools/EXAM_REPORT_GUIDE.md`](../tools/EXAM_REPORT_GUIDE.md).
