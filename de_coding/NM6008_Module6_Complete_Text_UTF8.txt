Step 9.1｜Post-CTS Setup + Hold 优化（本实验最关键！）
Manual P17 明确要求 post-CTS Setup/Hold 检查、必要时优化；你在 scripts/CHIP.tcl 第 120–138 行执行的
标准流程如下。先 check，再 opt，再复测：




                                  NM6008 M6 | SOP / Debug | 14
 Innovus Tcl
 timeDesign -postCTS -pathReports -drvReports -slackReports \
   -numPaths 50 -prefix postCTS_setup_before -outDir timingReports
 setOptMode -fixCap true -fixTran true -fixFanoutLoad true
 optDesign -postCTS

 timeDesign -postCTS -hold -pathReports -slackReports \
   -numPaths 50 -prefix postCTS_hold_before -outDir timingReports
 setOptMode -fixCap true -fixTran true -fixFanoutLoad true
 optDesign -postCTS -hold
 optDesign -postCTS -drv

 timeDesign -postCTS -pathReports -drvReports -slackReports \
   -numPaths 50 -prefix postCTS_setup_after -outDir timingReports
 timeDesign -postCTS -hold -pathReports -slackReports \
   -numPaths 50 -prefix postCTS_hold_after -outDir timingReports




 检查点：先别以单次 Hold 优化结束：DRV 再优化可能改变 Hold；必须使用新前缀输出 Setup 与 Hold 复
 测。你之前出现 53→5→21 的变化就是例子。

Post-CTS 初次                         −2.492 ns                           53

Hold 优化后                            约 −0.001 ns                         5

DRV 优化后                             −0.014 ns                           21

最终 Post-Route                       +0.419 ns                           0

Step 10.1｜按 Manual 做 Post-Route Timing

  Innovus Tcl
  # 若需要改变分析模式，优先按手册 P18 的 GUI 设置 OCV；
  # 使用工具支持的 Tcl 参数时必须在 innovus >，而不是 Linux shell
  setExtractRCMode -engine postRoute -effortLevel signoff \
    -coupled true -capFilterMode relAndCoup -coupling_c_th 0.1 \
    -total_c_th 0 -relative_c_th 1 \
    -lefTechFileMap ./GDS/22FDSOI_10M_2Mx_5Cx_1Jx_2Qx_LB_qrc_leftech.map
  # Manual P18 的 setAnalysisMode -analysisType onChipVariation 也可由 GUI 设置
  # 如果该命令的精简用法在本机不支持，请以完整 Manual 参数 / help 为准。
  setAnalysisMode -cppr none -analysisType onChipVariation

  timeDesign -signoff -pathReports -drvReports -slackReports \
    -numPaths 50 -prefix final_route -outDir timingReports
  timeDesign -signoff -hold -pathReports -slackReports \

Section 1: Introduction
This tutorial style laboratory manual document is meant for NTU-TUM Master of Science
(MSc) course – Integrated Circuit (IC) Design, NM6008. This module introduces the concepts
that serve as a bridge between modelling and synthesis to the actual physical layout level of an
IC system. The following sub-sections state the objectives, the design tools/process used and
the experimental design information of this module – Layout of Matrix Multiplier circuit.

1.1    Objective

       Module 6 gives a quick introduction to the Place & Route layout implementation. The
       design example used is the Matrix Multiplier Circuit. The primary objective of this
       module is to let students familiarize themselves with the Cadence IC Place & Route
       layout tool (and the associated design methodology). The specific objectives include:

       (i)    To complete a layout using the standard library cells; and
       (ii)   To learn the design methodology of the semi-custom IC layout implementation.
