# 05 · FSMs and protocols

This section contains Moore/Mealy FSM examples, password lock, debounce,
pulse-width measurement, PWM, request/acknowledge, sequence detection, registered
FSM outputs, and vending-machine control. The child READMEs list each interface
and testbench top.

Run `make test`, check state transitions and output timing in the waveform, and
run `make clean`. Use the exact question's reset and handshake contract.
Synthesis/report guidance: [`../tools/EXAM_REPORT_GUIDE.md`](../tools/EXAM_REPORT_GUIDE.md).
