# 改题练习：8 位、低有效同步复位串行加法器

> **自拟练习，不是往年真题。**从 [28 号模块化串行加法器](<../28_M345模块化串行加法器/28_模块化串行加法器_全流程.md>)改来，专练考试看到“位宽、复位方式变了”时如何同时修改 RTL 和 tb。更完整的改题思路见[综合题参考题库](<../00_M345综合题参考题库与举一反三.md>)。

## 题目规格（本练习自行规定）

- 顶层 `SerialAdder8`；输入 A/B 8 位、N 4 位、`CLK/NRST/START`；输出 SUM 8 位、COUT、DONE。
- `NRST=0` 为**同步复位**：只有在时钟上升沿才清状态、数据和输出。
- 在空闲态的上升沿接受 START 并锁存 A/B/N；之后每个上升沿只处理 1 位，共 N 个计算沿；DONE 在最后一个计算沿后高 1 拍。忙时 START 忽略。
- 本练习规定 `N=0` 或 `N>8` 按 8 位处理；结果对齐 SUM 低位，COUT 为第 N 位进位。真实考试按真实题面，不继承这里的额外规则。
- tb 半周期 10 ns，完整时钟周期 20 ns。

## 四个文件各负责什么

| 文件 | 具体改动 |
|---|---|
| [FullAdder.v](FullAdder.v) | 一位全加器，**与 28 号相同**，不用改 |
| [SerialAdder8Controller.v](SerialAdder8Controller.v) | N/index/width_q 改 4 位，最大运算位数改 8；状态机改同步复位 |
| [SerialAdder8.v](SerialAdder8.v) | A/B/SUM/移位寄存器改 8 位；顶层寄存器块改同步复位 |
| [SerialAdder8_tb.v](SerialAdder8_tb.v) | 输入/输出和黄金答案改 8 位；检查 1～8 位、溢出、非法 N 练习规则；**专门检查复位必须等时钟沿** |

## 本机行为仿真怎么跑

在有 `iverilog` 的电脑上，进入**本例四个 `.v` 所在目录**运行：

```sh
iverilog -g2001 -s SerialAdder8_tb -o /private/tmp/SerialAdder8_sim \
  SerialAdder8_tb.v SerialAdder8.v SerialAdder8Controller.v FullAdder.v
vvp /private/tmp/SerialAdder8_sim
```

若当前工作目录是本文件夹，运行会在这里写 `Check.txt`；仅用于检查，不属于 RTL 源码。本人已用本机 Icarus Verilog 跑出 **17 tests, 0 errors**。GF22 综合、SDF 门级仿真和功耗**尚未在学校机房验证**。
