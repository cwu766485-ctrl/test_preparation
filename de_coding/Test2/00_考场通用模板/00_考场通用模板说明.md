# Test 2 考场通用模板：先看题面，再改 RTL 与 testbench

这里有两套**可以直接编译运行的骨架**，用于快速起步，不是通用正确答案。现在的示例功能都是 XOR，目的是先确认时钟、复位、文件、输入向量和自动检查流程正常。实际题目必须按规格修改。

| 题目形态 | 用哪套 | 文件 |
|---|---|---|
| 加法器、MUX、比较器、ALU 等纯组合电路 | [组合逻辑模板](组合逻辑模板/) | `ExamComb.v`、`ExamComb_tb.v`、`InputVector.txt` |
| 计数器、FSM、串行运算、逐拍累加等时序电路 | [时序电路模板](时序电路模板/) | `ExamSeq.v`、`ExamSeq_tb.v`、`InputVector.txt` |

对于具体的串行加法/减法，优先对照已经做好的 [17 串行加法器](../17_可变位宽串行加法器/17_SerialAdder_讲解.md) 和 [27 串行减法器](../27_可变位宽串行减法器/27_SerialSubtractor_讲解.md)。矩阵乘法这类题的数据通路不同，不能只替换模板中的一行运算。

## 拿到题面后，按这个顺序改

1. **写清规格**：输入和输出名、位宽、有无时钟、复位极性、何时采样输入、运算需要几拍、`DONE`/进位/借位的定义。先画一个 2–4 拍例子。
2. **改 RTL 端口和功能**：组合版改 `EDIT 1/2`；时序版改 `EDIT 1–5`。时序逻辑用 `<=`，组合逻辑用 `=`；组合块的每条路径都必须赋值。
3. **同步改 testbench**：实例化端口、`EDIT TB-1` 的期望结果、时序版 `EDIT TB-2` 的延迟与输出判断、定向输入向量。**只改 RTL 不改期望值，会把正确的新设计报成 FAIL。**
4. **先测最小边界**：零、全 1、最大位宽、最小位宽、进位/借位、复位、连续两次启动。再跑随机测试。
5. **按题面改工程名**：RTL `module` 名、tb 里的实例化和 `U1`、综合脚本顶层名、`Syn_*.sdf`、功耗脚本里的实例路径必须一致。保留 `U1` 可少改 SDF/SAIF 路径。

如果考试改成高有效复位：把 `negedge NRST` 和 `if (!NRST)` 一起改，并同步改 tb 的复位激励。如果输出在完成后才更新，testbench 的采样时刻也必须随之修改。若题目是逐位从外部输入，时序模板的“一次装入 A/B”结构不适用，可参考 [19 位串行加减法器](../19_位串行加减法器/19_BitSerialAddSub_讲解.md)。

## 在这台 Mac 上运行

进入所选子文件夹，在该文件夹打开终端。时序版：

```sh
iverilog -g2012 -s ExamSeq_tb -o simv ExamSeq_tb.v ExamSeq.v
vvp ./simv
```

组合版：

```sh
iverilog -g2012 -s ExamComb_tb -o simv ExamComb_tb.v ExamComb.v
vvp ./simv
```

未修改的示例应分别显示 `72 sequential cases, 0 errors` 和 `136 combinational cases, 0 errors`。`InputVector.txt` 必须在运行 `vvp` 时的当前目录；`Check.txt` 会记录 PASS/FAIL。时序版输入每行 `NN_AAAA_BBBB`（十六进制，N/A/B），组合版每行 `AABB`（十六进制，A/B）。增加或删除行时，改 tb 顶部的 `NUM_VECTORS`。

## 机房流程与边界

机房用 VCS 时，保留 tb 中的 `VCS` 波形部分；门级仿真时再启用 `GATE_SIM` 的 SDF 反标。两份模板都把 DUT 例化为 `U1`，便于沿用课程功耗分析路径。门级仿真有真实延时；若 tb 的 `#2` 或 `#5` 采样太早，需按时钟周期和 SDF 延时调整。

**当前验证范围**：这台 Mac 上的 Icarus Verilog 行为仿真。综合、门级仿真、功耗与工艺库映射仍要在机房验证。考试是否允许复制文件，以现场规则为准。
