# Test 2：M3 + M4 + M5 综合题参考题库与改题方法

> **这是复习用的自拟参考题库，不是老师公布的题库或概率预测。**有证据的是：Test 1 曾把基础门组合成新电路；一位学长的 2025 Test 2 报告题目是 n 位串行加法器，采用一位全加器、状态控制和寄存器。由此优先练“运算单元 + 控制器 + 数据通路”是合理准备方向，但今年题目、端口、评分步骤均以现场题面为准。

## 1. 先把 M3、M4、M5 记成三种零件

```text
M3：组合运算单元       例如 1 位全加器、比较器、MUX
M4：时序控制           例如 IDLE/RUN 状态机、计数器、START/DONE
M5：寄存器数据通路     例如锁存输入、右移、累加、保存结果

综合题 = 控制器决定“哪一拍做什么” + 数据通路保存数据 + 运算单元完成当拍运算
```

**可以复用的是思路和接口符合题面的模块**。例如 [28 号例题](<28_M345模块化串行加法器/28_模块化串行加法器_全流程.md>)能直接例化 M3 风格的 `FullAdder`；M4 原来的状态机、M5 原来的矩阵乘法器做的是不同运算，通常不能原封不动例化。

### 可用来自己模拟考试的四段题面（均为自拟）

1. **A 的变体，已有完整参考实现：**设计 8 位串行加法器；低有效同步复位，START 在空闲态被采样；每拍处理一位，N 可变；输出 SUM、COUT，完成时 DONE 高一拍。参考 [29 号](<29_八位同步复位串行加法器/29_八位同步复位_改题说明.md>)。练习时先只读规格，不看代码。
2. **B 的变体，未提供可直接交卷的成品：**设计 8 位串行加/减法器，`SUB=0` 加、`SUB=1` 减；START 时锁存 SUB，处理 8 拍；输出结果和按题面定义的 carry/borrow。可从 28/29 的控制器与数据通路思路、19/27 的减法思路组合。tb 至少测 `7+9`、`9−7`、`7−9`、模式在运行中改变。
3. **C 的变体，未提供可直接交卷的成品：**设计无符号 4×4 移位相加乘法器，START 后 4 个计算沿输出 8 位乘积和 DONE；每拍检查乘数最低位、条件加、移位。参考 18 的结构。tb 至少测 `0×任意数`、`1×最大数`、`15×15` 与 DONE 拍数。
4. **D 的变体，未提供可直接交卷的成品：**依次输入 4 对 8 位无符号数，按拍计算四项乘积之和，START 清旧累加值，DONE 指示完成；结果位宽至少要容纳 `4×255×255`，即 18 位。参考 08/09。tb 逐项输入后用独立算式计算期望和，检查重新 START 后旧结果不残留。

这些模拟题故意写了不同的位宽、复位、拍数和标志规则；练习目标是**从现有零件推导新的 RTL/tb**。若真实题面另有规定，以真实题面为准。

## 3. 拿到新题，先填“规格卡”，不要马上抄代码

| 必须从题面找的事     | 自问一句                                     | 影响哪些文件                           |
| ------------ | ---------------------------------------- | -------------------------------- |
| **端口与顶层名**   | 输入输出叫什么？有没有 `START/DONE`、carry、borrow？   | 顶层 RTL、tb 例化、综合顶层 Tcl、SDF/SAIF 名 |
| **物理位宽 W**   | A/B/结果寄存器有几位？结果需 W 位还是 2W 位？             | RTL 端口/寄存器、tb 位宽和黄金答案            |
| **有效运算位数 N** | 是固定 W 位，还是运行时输入 N？N 要能表示 W 吗？            | 控制器计数器、终止条件、tb 的 N 测试            |
| **有符号/无符号**  | 负数和溢出如何定义？                               | RTL 运算和扩展、tb 黄金答案                |
| **复位**       | 高/低有效？同步/异步？复位时 SUM、DONE 怎么办？            | **所有带寄存器的 RTL 模块**和 tb 的复位时序     |
| **握手/延迟**    | START 在哪拍采样？忙时 START 怎么办？DONE 是一拍脉冲还是保持？ | 控制器、tb 计拍和连续交易检查                 |
| **输出规则**     | SUM 对齐低位还是高位？最后 carry/borrow 是什么？        | 数据通路和 tb 黄金答案                    |
| **交付要求**     | 只要 RTL/波形/综合，还是还要门级仿真/功耗？                | 决定 T1–T4 做到哪一步                   |

**题目没写的语义不能自作主张。**例如 28/29 号练习把 `N=0` 或 `N>W` 当 W 位，是这两份练习自己的约定；考试题面如果要求报错、忽略 START、输出零或根本不测试这些值，就按题面改 RTL 和 tb。

## 4. 真正举一反三：16 位异步复位 → 8 位同步复位

这里有两份**可以逐文件对照**的完整练习：

| | 基础版 | 改题版 |
|---|---|---|
| 目录 | [28：16 位、低有效异步复位](<28_M345模块化串行加法器/28_模块化串行加法器_全流程.md>) | [29：8 位、低有效同步复位](<29_八位同步复位串行加法器/29_八位同步复位_改题说明.md>) |
| A/B/SUM | 16 位 | 8 位 |
| N、index | 5 位，需能表示 16 | 4 位，需能表示 8 |
| 复位敏感列表 | `posedge CLK or negedge NRST` | **只有** `posedge CLK` |
| FullAdder | 仍然只是 1 位，无需改 | 原样复用 |
| tb 期望答案 | 17 位中间和；按 N 取结果/carry | 9 位中间和；按 N 取结果/carry；增加同步复位检查 |

### 4.1 RTL：位宽到底要改哪几处？

看 [29 顶层 RTL](<29_八位同步复位串行加法器/SerialAdder8.v>) 和 [29 控制器](<29_八位同步复位串行加法器/SerialAdder8Controller.v>)：

```verilog
// 顶层：物理数据宽度 W=8。
input  wire [7:0] A, B;
input  wire [3:0] N;      // 4 位才能表示数字 8；[2:0] 最大只有 7。
output reg  [7:0] SUM;
reg    [7:0] a_q, b_q;

// 控制器：计数与锁存宽度也要改。
reg [3:0] width_q;
output reg [3:0] INDEX;
// 本练习才约定非法 N 按 8 位做；真实题目按题面。
width_q <= (N == 4'd0 || N > 4'd8) ? 4'd8 : N;
```

**只改端口 `[15:0]` 不够。**内部 A/B 寄存器、SUM、N、计数器、`16` 这个最大值、所有相关字面常数、tb 黄金答案都得核对。`FullAdder` 还是 1 位，所以不需要改成 8 位全加器。不要全局把文本里的 `16` 一键换 `8`：例如“中间和位宽应是 W+1”需要你理解后写成 9 位，不能机械替换。

### 4.2 RTL：同步复位到底改哪两处？

**原版异步低有效**在控制器和顶层都有这样的寄存器块：

```verilog
always @(posedge CLK or negedge NRST) begin
    if (!NRST) begin
        // 清状态、寄存器、结果
    end else begin
        // 正常工作
    end
end
```

**同步低有效**要把这两个模块的寄存器块**都**改为：

```verilog
always @(posedge CLK) begin
    if (!NRST) begin
        // 清状态、寄存器、结果
    end else begin
        // 正常工作
    end
end
```

`if (!NRST)` 仍表示**低电平有效**；删除敏感列表中的 `negedge NRST` 才是把复位改为**只在时钟沿生效**。如果题面是**高有效同步 `RST`**，则条件应为 `if (RST)`；这是有效电平和同步/异步**两个独立选择**。寄存器出现在哪个 RTL module，就检查那个 module 的复位；漏改控制器会出现“数据清了、状态没清”的怪现象。

### 4.3 tb：怎么让测试真的发现改错？

看 [29 testbench](<29_八位同步复位串行加法器/SerialAdder8_tb.v>)。它不是简单把 16 换成 8，还改了：

```verilog
reg  [7:0] A, B;
reg  [3:0] N;
wire [7:0] SUM;
reg  [8:0] full;   // 8 位加法可能产生第 9 位进位。

// 先用 tb 独立算期望值，再与 DUT 比较。
width = (nn == 0 || nn > 8) ? 8 : nn;
mask = (width == 8) ? 8'hFF : ((8'h01 << width) - 8'd1);
full = {1'b0, (aa & mask)} + {1'b0, (bb & mask)};
expected_sum = full[7:0] & mask;
expected_cout = full[width];
```

测试例要随着位宽变：`8'hFF + 8'h01` 检查最大位宽溢出；`N=1`、`N=8` 检查边界；例如 `N=0/9` 只用于这份练习自己定义的非法值规则；`for (i=1; i<=8; i=i+1)` 覆盖 1～8 位。**tb 的期望结果要由规格直接计算，不要抄 DUT 内部每拍实现，否则同一种错可能两边一起错。**

同步复位还需要一个**能区分同步和异步的测试**：先让 `SUM` 成为非零，然后在时钟下降沿拉低 `NRST`；下个上升沿**之前**检查 `SUM` 仍保持旧值；经过一个上升沿后再检查 `SUM/COUT/DONE` 清零。仅在仿真一开始把复位拉低，通常无法证明它是同步复位，因为输出本来可能就是零。

本机用 Verilog-2001 编译运行 [29 号代码](<29_八位同步复位串行加法器/29_八位同步复位_改题说明.md>)，**17 项检查、0 errors**；GF22 综合、SDF 与功耗仍要在机房验证。

## 5. 其它常见改题词：RTL 与 tb 要成对改变

| 题面改了什么 | RTL 怎么改 | tb 必须新增什么检查 |
|---|---|---|
| **结果只取低 W 位** | 明确截断，别无意中丢最高进位 | 最大数加法、溢出时输出是否按题意截断 |
| **需要 `COUT` 或借位** | 定义最后进位/借位的意义；减法用补码实现时 carry=1 常表示“无借位”，不能不加说明 | `A<B`、`A=B`、`A>B` 分别检查结果和标志 |
| **有符号数** | 端口/中间结果的符号、扩展与截断规则重新核对 | 正+正、负+负、正+负、边界值；黄金模型按题面解释符号 |
| **DONE 变成保持到下次 START** | 控制器不能每拍无条件清 DONE；在接受新 START/复位时清零 | DONE 完成后保持多拍；下次开始时清零 |
| **DONE 只高 1 拍** | 如 28/29 控制器每拍默认 `DONE<=0`，最后一拍设 1 | 完成拍为 1、下一拍为 0 |
| **忙时 START 如何处理** | 明确忽略、排队还是重新开始；通常要改状态机 | RUN 中再给 START，检查输出和完成拍数 |
| **复位发生在运算中间** | 状态、计数、数据寄存器、输出按题面清/保持 | 运行几拍后拉复位，再重新 START，确认旧结果不残留 |
| **N 固定或非法 N 规则不同** | 改宽度锁存、终止比较、N=0/>W 处理 | N=1、N=W；非法值只按题面要求测试 |
| **输入是逐位到来，不是一次输入 W 位** | 数据通路接口和采样时序要重设计；不能只改端口名 | 每个时钟沿送一位，检查输入顺序和最后输出 |

### 5.1 最稳的 tb 写法：驱动、等待、比较分开

```verilog
// 1. 在下降沿改变输入，给下一个上升沿留出稳定时间。
@(negedge CLK);
A = aa; B = bb; START = 1'b1;

// 2. 下一次下降沿撤掉 START；此时前一个上升沿已采样。
@(negedge CLK);
START = 1'b0;

// 3. 按题目规定等待 N 个计算沿或等 DONE，设超时上限。
// 4. 用独立计算的 expected_sum/expected_flag 与输出逐项比较。
// 5. 失败时打印输入、实际值、期望值、拍数，便于定位。
```

**时序规则先画表，再写代码。**把“第 0 沿装载、第 1 沿处理 bit0、……、第 N 沿完成”写清楚；如果题面要求“START 同拍就算第一位”，拍数会不同，不能照搬 28/29 的 tb。

## 6. 三小时考试的做题顺序
