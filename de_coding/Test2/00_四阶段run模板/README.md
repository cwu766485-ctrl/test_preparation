# Four-stage run template

The `Behavioral/`, `Synthesis/`, and `rtl/` scripts are course-machine templates
for behavioral VCS, Design Vision synthesis, gate simulation, and power
analysis. First read [`00_使用说明.md`](00_使用说明.md), then edit the project
configuration and top-specific Tcl to match the exam question. These scripts
require the course Synopsys setup and GF22 library.
