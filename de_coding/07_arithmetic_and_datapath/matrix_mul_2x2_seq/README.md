# Mock3：时序 2×2 矩阵乘法器

## 题目与接口

这是一个无符号 2×2 矩阵乘法器。矩阵按行优先打包：

- A_flat = {a00, a01, a10, a11}
- B_flat = {b00, b01, b10, b11}
- C00 = a00×b00 + a01×b10
- C01 = a00×b01 + a01×b11
- C10 = a10×b00 + a11×b10
- C11 = a10×b01 + a11×b11

每个输入元素为 8 位，每个输出元素为 17 位。接口还包含低有效异步复位 rst_n、启动 start、忙信号 busy 和完成脉冲 done。启动时采样 A_flat/B_flat；计算期间输入可改变，且新的 start 会被忽略。

## RTL 电路说明

RTL 位于 rtl/matrix_mul_2x2.v，顶层模块为 matrix_mul_2x2。

- a_hold、b_hold 是输入寄存器，只在空闲状态接受 start 时锁存矩阵。
- busy 表示控制器正在运行；3 位 step 计数器依次选择 8 个标量乘积。
- 组合多路选择器从锁存的 A/B 元素中选出当前乘数。8 次运算依次服务 C00、C01、C10、C11，每个结果累加两项。
- 一个 8×8 乘法器生成 16 位 product；一个 17 位加法器把 product 加到当前输出元素。乘法和累加硬件在各项之间复用。
- 接受 start 的时钟沿清零四个 C 输出并置 busy。之后每个时钟沿完成一项；第 8 项完成时 busy 清零并让 done 拉高一个周期。
- rst_n 拉低会异步中止运算并清空状态、输出和握手信号。运算中途的 C 输出可能是部分和；应在 done 有效时读取最终结果。

示例 A=[1,2;3,4]、B=[5,6;7,8]，结果应为 C=[19,22;43,50]。最大结果为 2×255×255=130050，可由 17 位无符号数表示。

## TB 与文件

- tb/tb_matrix_mul_2x2.sv：自检行为级 TB。覆盖示例、全零、单位矩阵、最大值、忙时改输入/再次启动、异步复位、复位恢复和 120 组确定性伪随机矩阵；逐周期比较四个 C、busy 和 done。
- tb/tb_matrix_mul_2x2_gate.sv：门级 SDF 独立 TB，需要综合网表、SDF 和工艺库仿真模型。
- scripts/：Design Vision 综合脚本模板。它依赖机房提供的 GF22 环境与库文件。
- docs/：题目截图和测试计划。

## VCS 仿真

在本目录运行：

    make test
    make clean

test 会用 VCS 编译并运行自检 TB；编译文件、日志和 VCD 位于 build/。clean 删除 build/。门级 SDF、功耗和综合不包含在此 RTL 回归中；若题目要求报告流程，按 [考试报告流程](../../tools/EXAM_REPORT_GUIDE.md) 并使用机房授权的工具和库。

仿真通过只表示 TB 覆盖的用例通过，不是形式验证，也不代替综合和门级检查。
