# 02 · Sequential logic

This section contains counters, DFFs, edge detectors, clock dividers, clock
muxes, sequence detectors, shift registers, and state sequences. The
[`counters/README.md`](counters/README.md) separates the up, down, and mod-N
variants and their testbenches.

From an exercise directory use `make test`, review the reset/state/count
waveforms, and finish with `make clean`. Follow the question's reset polarity
and timing even if the practice module differs.

Synthesis and report steps are in [`../tools/EXAM_REPORT_GUIDE.md`](../tools/EXAM_REPORT_GUIDE.md).
